# Changelog

## 1.0.0

First public release.

- Brief mode: a ColorOS-style banner with a One UI animation for each new notification.
- Detailed mode: notification cards on the AOD, up to four at a time.
- Position, banner duration, colored or monochrome icons.
- Latest notification on tap, when power saving has hidden the AOD clock.
- Pocket check, and respect for the lock screen content setting and private apps.
- Settings screen made of the real ColorOS components, and a Notifications row in the system AOD settings.
- The interface follows the system language: 67 languages, every language ColorOS offers.
