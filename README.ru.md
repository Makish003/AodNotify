# AOD Notify

Краткие и подробные уведомления на Always-On Display в ColorOS 17, как в One UI.
Модуль LSPosed (современный API libxposed 101/102).

[English](README.md)

## Возможности

- **Кратко**: плашка в стиле ColorOS с анимацией One UI на несколько секунд показывает новое уведомление.
- **Подробно**: карточки уведомлений остаются на AOD, до четырёх одновременно.
- Положение (сверху, по центру, снизу), длительность плашки, цветные или монохромные значки с выбором цвета.
- **Последнее уведомление по касанию**: когда энергосбережение скрыло часы AOD и вы касаетесь экрана, вместе с часами появляется последнее уведомление и исчезает вместе с ними.
- Проверка кармана: в кармане ничего не показывается.
- Учитывается системная настройка скрытия содержимого на экране блокировки и приватные приложения.
- Экран настроек собран из настоящих компонентов ColorOS из системных «Настроек» (размытие под заголовком, стеклянная кнопка «Назад»). Если их не удаётся загрузить, открывается похожее собственное оформление.
- В системных настройках появляется пункт **Уведомления**: Главный экран, экран блокировки и стиль → Всегда включенный дисплей → Настройки отображения → Уведомления.
- Язык интерфейса следует за языком системы: 67 языков, все, что предлагает ColorOS.
- Настройки применяются сразу, перезапуск не нужен.

## Требования

- ColorOS 17. Разработано и проверено на OnePlus 15T (китайская прошивка), приложение AOD 17.001.0021. Другие сборки ColorOS 17 должны работать. На других версиях пункт в системных настройках может не появиться, тогда модуль эту страницу не трогает.
- Root и LSPosed 2.x с libxposed API 101 или новее.

## Установка

1. Установите APK.
2. LSPosed → Модули → AOD Notify: включите. Область: **Системный интерфейс** и **Всегда включенный дисплей** (`com.oplus.aod`). Второе нужно только для пункта в системных настройках; модуль сам попросит её при первом запуске, подтвердите в уведомлении LSPosed.
3. После установки или обновления перезапустите SystemUI (или перезагрузите телефон). Для пункта в настройках также закройте «Всегда включенный дисплей» из недавних после того, как добавили область.
4. Откройте AOD Notify и выберите режим.

Чтобы всё вернуть, выключите модуль в LSPosed и перезапустите SystemUI. Модуль не меняет системные настройки и не трогает файлы.

Логи: LSPosed → Журналы (строки `AodNotify`).

## Сборка

Без Gradle: `build.sh` сам вызывает aapt2, javac, d8, zipalign и apksigner. Нужны JDK 17+, Python 3 и Git Bash на Windows.

Положите в `tools/` эти файлы из Android SDK (или укажите папку с ними в `TOOLS`):

| Файл | Где взять в Android SDK |
| --- | --- |
| `aapt2.exe`, `zipalign.exe`, `libwinpthread-1.dll` | `build-tools/36.x/` |
| `d8.jar`, `apksigner.jar` | `build-tools/36.x/lib/` |
| `android.jar` | `platforms/android-36/` |

```bash
VERSION_CODE=1 VERSION_NAME=1.0.0 bash build.sh
```

APK появится в `out/`. При первой сборке в `keystore/` создаётся ключ подписи. Сохраните его: обновление встаёт поверх старой версии только с тем же ключом. Если JDK лежит не в `C:/Program Files/Java/jdk-25/bin`, задайте `JDK_BIN`.

В `libs/` лежат jar-файлы [libxposed](https://github.com/libxposed) (API, interface, service; Apache License 2.0).

### Переводы

Строки лежат в `res/values-*/strings.xml`, английский в `res/values`. Пункт в настройках AOD создаёт код самого AOD, а он не умеет читать ссылки на строки модуля, поэтому `build.sh` пишет `res/xml-*/aod_entry.xml` для каждого языка из его `aod_entry_title`. В языках с письмом справа налево строка, начинающаяся с латинского названия (AOD, ColorOS), открывается невидимым знаком U+200F, чтобы остаться выровненной по правому краю.
